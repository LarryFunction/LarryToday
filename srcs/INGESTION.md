# 后续接入资料

这是一份接入研究清单，不是已经实现的采集系统。具体URL、鉴权说明和检查结果见 `integrations.json`；没有核实的公共接口留空。

## 建议先后顺序

1. **格式清晰的公开材料**：从已经解析的Guardian、BBC、France 24、Fed、NASA订阅和USGS GeoJSON开始设计适配器；另安排arXiv空订阅复查。五个有内容订阅可直接通过 `feeds.checked.opml` 导入阅读器。
2. **一手数据与文书**：SEC、World Bank、FRED、BLS、Crossref、arXiv、ReliefWeb。先阅读各自文档、鉴权和分页要求，不将所有API套入同一种参数模板。
3. **网页与动态披露站**：财新、第一财经、巨潮、HKEX及地方媒体。确认官方可用订阅、公告下载和许可后接入，不能假设每个网站都有RSS。
4. **商业供稿与聚合服务**：Reuters、AP、AFP、Bloomberg、FT、NewsAPI等。评估实际商业合同及覆盖，保留元数据和原文链接；不能把聚合接口当全文授权或独立证据源。
5. **社区与社交平台**：既有X账号、论坛、视频平台仅进入线索池。账号身份、原始帖子、发生时间和地点均须验证；不以转发量或订阅量决定事实成立。

## 本轮端点实测

2026-10-18，对8个公开端点作只读请求并解析格式。Guardian、BBC、France 24、Fed、NASA的RSS含条目；USGS GeoJSON通过形状检查。arXiv cs.AI返回有效RSS但条目为0；这不能推出停更，需在后续发布周期复查。ECB订阅遇本机证书链校验失败，未关闭TLS验证；这不能推出网站宕机。

网页浏览工具不善于读取XML/JSON，因此网页日志中的“读取失败”与直接探测中的“格式成功”可以同时成立，二者方法不同。对已通过格式检查的订阅也未承诺更新时效或所有条目可免费阅读全文。

## 采集元数据建议

每条文章或公告至少保存：`source_id`、`original_url`、`canonical_url`、`title_original`、`language`、`author`、`publisher`、`published_at`、`updated_at`、`fetched_at`、`content_type`、`upstream_agency`、`original_document_ids`、`license_status`。

时间保留来源时区并转换为UTC；展示时再换算用户时区。区分“事件发生时间”“报道发布时间”“文档生效时间”“抓取时间”，不得用抓取时间代替发布时间。转载翻译须同时记录原始语言和译文来源。

财务指标保留币种、单位、统计期、季调、名义/实际、同比/环比、财年、初值/修订值。AI模型保留模型版本、代码commit、权重许可、评测集、提示模板、样本数及日期。学术材料保留DOI/arXiv ID、版本及撤稿/更正关联。

## 更新和去重

- HTTP条件请求、官方分页和明确限速按各站文档实现，不在此假定通用频率。遇429/403停止或退避，不把挑战页当正文。
- canonical URL、通讯社署名、原始文书编号、全文相似度用于文章级去重。仅域名去重不足以识别转载。
- 更正、撤稿、财报修订、伤亡数字变化使用版本链；不能静默覆盖之前的判断和证据。
- 页面结构或域名变化先复核身份。目录保留了Animal Político、AMD、LMArena、Global Forest Watch等观察到的跳转，不能仅凭自动跳转认定新站所有内容具有相同授权。

## 原清单的复核重点

原文件的“197个国家”“可直连”“权威”“独立”等表述仅作为用户原始笔记保留，本轮不重复背书。不同语种子站和通讯社转载往往产生大量URL，但没有对应数量的独立信息链。

`ABC` 在原精选列表中有歧义，扩充目录明确区分美国ABC与澳大利亚ABC；巴拉圭ABC Color仍保留在原URL索引。旧域名、网站名与说明明显不匹配的条目（例如原文将 `minjok.com` 标成特定朝鲜官方机构）不应凭名称直接启用，须核对当前机构介绍及官方反向链接。这里提出的是待查问题，不作未经验证的替代归属判断。

所有权、资助、合作稿件和母机构的关系需要持续审计；目录少量family hint仅作提醒。尤其是企业博客、赞助内容、民调、商业研究、倡议组织和当事国声明，应明确利益关系及方法边界。
