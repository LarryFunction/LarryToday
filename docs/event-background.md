# 事件背景与延伸阅读

背景模块位于事件档案内、争议与时间线之前，使用现有分类主题色。列表和首屏不下载背景正文。

- 来路：从当前阅读刊期之前的已收录报道取出较早一条，保留原文和日期；不引用未来刊期。
- 知识卡：匹配会议、机构、选举制度、经济政策、AI、预印本等，展示简短中文解释与官方来源。
- 国家：依据报道地域展示概况及历史入口。初始包含美、法、英、日的基础制度简介；其他国家提供明确标注的百科检索入口，不假定同名词条存在。
- 延伸阅读：以报道标签或标题提供百科检索。检索链接不是经过核实的具体词条，也不用于生成事实。

共享资料库位于 `srcs/background-context.json`，部署时复制为 `api/background-context.json`。首次打开事件档案才请求，浏览器会话内复用；失败后仍显示已有的历史报道与检索入口，下次可重试。单个事件最多三张知识卡、三个国家，避免背景压过新闻。

新增条目需提供稳定的主题 ID、保守匹配表达式、中文解释、来源 URL 和链接类型；同组条目优先使用更具体的规则。例如美国选举覆盖通用选举规则，避免重复。当前整理日期为 2026-11-18，已核对主要机构页面；外部资料可能更新，阅读旧刊时需结合资料整理日期。

此版不新增任何 AI 请求，也不按每篇报道重复检索。已整理的背景不会随着每天报道反复生成。资料覆盖不足时如实显示，后续可继续扩充共享资料库。
