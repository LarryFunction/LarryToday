# 地域标识设计与识别规则

## 排版与图形

国家代码保留全大写（CN、US），说明词使用首字母大写（Multi、Research）。中文采用宋体／衬线字体栈，沿用各新闻板块的配色。

| 图形 | 含义 |
| --- | --- |
| 单圆 | 单一国家 |
| 两个交叠圆 | 两个相关国家 |
| 三个交叠圆 | 三个或更多相关国家（不是精确数量图） |
| 经纬网格 | 明确的区域或全球范围 |
| 菱形 | 主题归属；不表达国家 |

未识别到明确国家或区域时，按版面显示 Affairs 国际事务、Tech 科技与智能、Markets 经济与市场、Research 科学研究、Climate 环境与气候、Culture 社会与文化。研究来源优先显示 Research；缺少版面元数据的旧记录显示 Topics 专题观察。Space 太空探索属于范围标识。

不用图形区分“发达／发展中”：避免分类口径变化、争议和额外维护；色彩继续表示新闻版面。

## AI 与额度

国别识别合并到现有翻译、摘要和标签请求，独立输出 country_mentions，每项仅含 code 与 evidence（原始标题或 RSS 摘要中的短引文）。不改变 tags 的主题用途，不额外请求全文，不增加独立国别 API 调用。新增字段会带来少量输入与输出 token，仍受现有总预算和重试计费机制约束。

模型只识别主要相关国家，允许明确城市或机构对应的国家，不根据媒体所在地、作者或泛泛背景推断。最多八国，按重要性排序。服务端验证代码、字段大小及引文是否出现在输入材料；这属于来源依据检查，不能保证模型归属判断完全正确。

缺失或不合法的国别字段回退到本地内容匹配，不丢弃新闻、不单独重试。合法空数组表示模型未找到明确国家，转入区域／主题标识。没有 AI 时仍可正常发布。

保留原缓存版本：已有缓存不因新增字段失效，不自动重跑历史新闻；新生成的新闻逐步获得 AI 国别字段。历史数据在构建时使用本地规则生成新样式，不产生 API 费用。需要云端 AI 编辑时仍须按现有部署指南配置 Secrets 并启用 AI_ENABLED；本次不改动其开关。
