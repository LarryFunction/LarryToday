# LarryToday 事件版（2026-11-10）

## 阅读方式

首页默认按事件阅读。同一具体事件的多家报道在一条下展开；条目保留中文概述、英文原题、栏目颜色、国别构成主义标识和标签。最新概述来自代表报道，不是各家报道的共同结论。点击标题或“事件档案”可查看按刊期排列的来源与进展。

“逐篇报道”保留原阅读方式。分类、关键词、标签搜索会检查事件中所有成员；晨读同一事件只出现一次。收藏针对原始报道，保留原刊快照；旧版收藏仍可访问。原始日报、初版和各次修订不会被事件视图改写。查看旧版本时，不把后来的归并判断或未来报道混入当时版面。

## 归并与追踪

基础归并使用标题特征、地域、事件动作和文献身份；不同 arXiv 论文不能仅因同题合并。同一文献不同版本可持续追踪。跨日匹配比同日匹配更严格，通常在最近 14 天的事件中寻找延续；若持续有新报道，时间线会继续延长。明确的同次美国中期选举和伊朗战争名称作为持续报道主题锚点，不将泛泛国家或人物关键词作为事件身份。

翻译完成后，可选的 AI 编辑会读取中文标题与短摘要，批量识别具体事件。每个成员须提供输入材料中的原句，未知 ID、重复成员、捏造引用和明显宽泛主题会被拒绝。归并结果连同依据保存在原报道字段和修订中，仍然可能有误，应结合来源抽查；无充分依据时保留独立条目。此次抽查已拆开不同地点的海难及宽泛规划、招聘/亮相等分组。

事件视图在构建时从各期最新修订重建，不额外调用 API。事件 ID 由最初锚定报道生成，新增后续刊期不会主动重命名既有事件；若人工修正早期归并，事件归属及 ID 可能变化。所有新闻保留，并非为了减少条数而强行合并。单篇事件直接使用已加载报道，持续或多源事件的档案按需加载，避免首页下载整个历史资料库。

## 事件之间的联系

目前展示“报道中的关联线索”，附来源链接、日期和原句。系统只有在材料明确包含“外溢、蔓延、波及、受启发”等联系且同时点明相关地域时，才为两个分立事件提供入口。不同国家的骚乱不会仅因日期或词语相似而合并。展示原句不等于独立确认因果；没有材料支持的联系留空。该规则偏保守，可能漏掉未明确写出的联系。

## 更新与费用

GitHub Actions 主任务改为 UTC `0 23 * * *`，对应北京时间每日 **07:00**。保留 08:47 的补跑。07:00 是触发时间；GitHub 排队、来源抓取、翻译和部署均可能造成延迟，并非准点上线承诺。截稿窗口仍为前一天 07:00 至当天 07:00。

每日共享上限仍为 **500,000 tokens**。先保障全量中文，AI 事件编辑最多占用其中 **60,000 tokens**，并复用缓存；不会额外增加每日上限。用尽或服务失败时使用本地归并，既有缺译暂存、断点续译机制保持。首次 11 月 10 日实测事件编辑使用 33,197 tokens，当天累计 226,781；930 篇报道全部保留（其中 12 篇背景阅读）。AI 分组经过抽查后再形成修订。

代码入口：`scripts/event_editor.py`（有额度约束的 AI 事件判断）、`scripts/event_graph.py`（事件阅读视图及跨期档案）、`scripts/build_pages.py`（静态输出）。
