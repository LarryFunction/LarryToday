# 未接入来源处理清单

> 此文保留2026-10-19历史排查背景。2026-10-20已完成部分修复，当前状态、剩余问题和逐步操作以 [信息源处理报告](source-treatment-report.md) 与 [自动审计](source-audit.md) 为准。

2026-10-19复测。来源目录是候选库，不能等同已建立采集通道。

| 状态 | 来源示例 | 处理方式 | 当前结果 |
|---|---|---|---|
| 正常空订阅 | arXiv | 验证RSS结构后标记暂无更新，继续定期采集 | 已修复，实测有效空RSS |
| 旧入口失效 | 中国日报 | 寻找官网当前订阅；没有可验证入口则做独立官网栏目适配 | 原入口仍404，尚无已验证替代入口 |
| 停更或连接失败 | 人民网、新华社现有RSS | 不把旧新闻当新稿；寻找当前栏目/API并单独验证日期和链接 | 本轮人民网仍过时；新华社连接失败 |
| 发布时间不完整 | Nature部分条目 | 从公开文章页核对时间；没有明确时分则仅用于背景资料 | 尚未实施文章页补时，不猜测时间 |
| 凭证待提供 | X观察账号 | 服务端配置专用凭证、确认访问权限及账号身份后启用 | 适配器已实现，尚未实测 |
| 仅目录收录 | 其余媒体、机构、个人网站 | 按地区缺口、主题价值、更新频率逐批审查；优先官方RSS/Atom/API | 尚未逐一检查，不能宣称都可自动采集 |

没有RSS不等于永远不能接入：可针对公开栏目制作网页适配器，只提取标题、时间、摘要和原文链接；这需要逐站验证页面结构与使用条件，也需要维护。需要订阅或供稿授权的来源使用其授权接口；在获得条件前可保留人工导入与原文目录入口。

个人观点可优先使用作者公开博客或Newsletter的RSS；这能补充科技AI观点，但不能声称已覆盖其X发言。

来源健康数据会随每次采集更新。日报历史内容不随来源状态变化而重写。来源配置并不意味着其每一条稿件都会进入当期，仍需满足截稿时间和选编条件。

arXiv官方说明：https://info.arxiv.org/help/rss_specifications.html （skipDays）
