# 事件优先阅读与热点溯源

首页以“今日事件”“持续追踪”组织阅读，两者表示内容范围，不再要求读者理解版本切换。专题分类仍在顶部。点击卡片上的“了解事件”打开档案，卡片下方展开各家来源。“全部报道索引”是辅助查阅入口，保留原有逐篇阅读、检索、分页与收藏；索引内提供明确的返回入口。

事件卡片中的摘要来自最新代表报道，并显示来源名称。不同媒体的说法保留在来源列表和跨期档案里，不能把来源数量当作独立证实次数。

## 可复用的热点溯源

`scripts/source_evidence.py` 每日最多选择三个事件，综合本期来源家族数量、报道数量、晨读入选情况排序。优先寻找机构原始材料，而非针对某一个人或公司写固定逻辑。

每个事件最多读取两篇报道中的引用链接、执行两次公开 RSS 搜索、尝试读取四个候选页面。只展示属于配置的一手机构域名、实际读取成功且标题与事件具有足够相关性的页面。搜索摘要不会当作证据，AI 不生成引文，也不会自动给事实下核验结论。正文摘录直接取自页面；找不到相关段落时仅列页面标题和来源。

`config/evidence-publishers.json` 配置机构名称、域名、识别词；配置的官方和研究订阅也会自动纳入。可以扩充政府、法院、企业、研究机构等域名。此名单表示材料发布者身份，不表示其陈述一定真实。所有外链必须使用 HTTPS，拒绝私有网络地址，重定向也经过校验。

结果保存为 `data/evidence/YYYY-MM-DD.json`，包括被选事件的原始报道 ID、检索词、读取时间、材料和失败阶段。网页通过报道 ID 将材料关联到事件档案，不修改原始新闻。历史刊期仅读取对应日期的手记。每日流程在新闻发布后执行，失败不阻塞日报；无 AI 费用，已完成结果不反复抓取，连接失败最多补试一次。操作记录可在 JSON 中检查。

## 当前边界

这是原始材料发现功能，并非自动事实裁判。公开搜索接口可能不可用或返回不相关结果；标题相关性规则偏保守，会漏掉换一种措辞的官方声明。未知机构尚未纳入域名表时也可能漏检。界面明确区分“连接不可用”和“本次未找到相关材料”。待人工核验的争议不能因为机构声明存在而被标记为证实。

本地验证：覆盖域名伪装、私网地址、无关官网、搜索摘要不冒充证据、页面归属和失败状态。日常观察可据记录扩充机构域名和检索规则，不必扩大 token 上限。
